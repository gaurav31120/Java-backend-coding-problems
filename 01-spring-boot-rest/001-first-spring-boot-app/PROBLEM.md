# Problem 1 — First Spring Boot App

## Objective

Create and run a basic Spring Boot application using Java 21 and Maven.

## Requirements

- Create a Spring Boot application.
- Use Java 21.
- Use Maven.
- Add Spring Web.
- Start the application successfully.
- Verify that the embedded web server starts.
- Configure the application name using `application.properties`.

## Expected Result

The Spring Boot application should start successfully and run on port 8080.

## Concepts Practiced

- Spring Boot
- Maven
- `@SpringBootApplication`
- `SpringApplication.run()`
- `application.properties`
- Embedded Tomcat
- Application configuration
